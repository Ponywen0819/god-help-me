\appendix{B}{視覺化神經纖維分析工具}
\label{app:tool}

為使第~\ref{chap:method}~章所述之 AEL 演算法得以互動執行、視覺檢驗、並進一步支援使用者於重建結果上手動修整再重新計數，本研究實作了一套桌面端之圖形使用者介面工具（以下簡稱\textbf{本工具}）。本附錄依序介紹設計動機、執行環境與系統架構、介面布局、典型工作流程、側邊欄分頁（檔案、圖層、演算法與纖維）、中央畫布、頂部工具列、互動模式、圖形編輯、遮罩塗改，以及檔案儲存與結果輸出。

\section{設計動機}
\label{sec:tool-overview}

第~\ref{chap:method}~章之 AEL 雖為一全自動之演算法流程，於臨床導入時仍存在兩項實務需求，設計一個專屬之操作介面有其必要：

\begin{enumerate}
  \item \textbf{中介產物之視覺檢驗：} AEL 除重建之纖維拓樸圖外，其最終量化指標為一純量計數 $N_{\text{pred}}$，而此計數之品質高度依賴前處理、成本圖與多源擴張等中介結果之合理性；臨床端使用者需能即時觀察各階段之輸出疊合於原始影像上，以判斷個別參數設定是否合理。
  \item \textbf{人為修整之回饋迴圈：} 於染色嚴重斷裂或微粒標註本身有誤之切片上，自動重建之結果未必能完全符合專家判讀；使用者需能於重建後直接在影像上新增、刪除節點與邊，並以修整後之拓樸重新進行有效神經纖維計數。
\end{enumerate}

本工具即針對此兩項需求設計：以多圖層疊合呈現中介產物、並提供互動式圖形編輯與重新計數。

\section{執行環境與系統架構}
\label{sec:tool-arch}

本工具為一跨平台之桌面應用程式，以 Electron 框架~\cite{electron2026}建構，可於 Windows、macOS 與 Linux 上執行。其使用者介面負責影像圖層之疊合呈現與互動式圖形編輯，而第~\ref{chap:method}~章所述之 AEL 演算法則以 Python 實作並作為後端運算核心。

\section{介面布局}
\label{sec:tool-layout}

本工具之主視窗分為三大區塊（圖~\ref{fig:tool-layout}）：

\begin{enumerate}
  \item \textbf{左側邊欄 (Sidebar)：} 該區域主要負責控制，並依照功能分成多個分頁。包括樣本讀取、圖層控制、演算法控制與纖維長度瀏覽。
  \item \textbf{頂部工具列 (Top Toolbar)：} 包含模式切換按鈕與當前樣本資訊顯示（有效神經纖維數與圖片大小），並且帶有重置重建圖按鈕。
  \item \textbf{中央畫布 (Canvas)：} 影像圖層與重建圖之疊合區域，支援平移、縮放與互動式編輯。
\end{enumerate}

\section{典型工作流程}
\label{sec:tool-workflow}

第一次使用本工具者，可依下列步驟完成「選定樣本 → 自動計數 → 重建結果修改 → 即時重新計數」之完整流程：

\begin{enumerate}
  \item \textbf{選擇工作目錄：}於左側邊欄之\textbf{檔案} (Files) 分頁點擊\textbf{選擇工作目錄} (Select Working Folder) 按鈕，選定一存放待分析樣本之工作目錄。該目錄下之每個樣本各為一子資料夾，其中依檔名前綴放置\textbf{原始影像}（\texttt{image}）、\textbf{表皮遮罩}（\texttt{epidermis}）與\textbf{纖維微粒遮罩}（\texttt{particle}）三張影像；本工具會掃描該目錄並於分頁中列出所有可用樣本。所選工作目錄會被記憶，下次啟動時自動回復。
  \item \textbf{選擇樣本：}於同一分頁之樣本清單點選欲分析之切片，本工具即\textbf{自動載入}該樣本之 RGB 原始影像、表皮二值遮罩與纖維微粒標註遮罩三層，毋需逐張手動上傳；若該樣本先前已有自動儲存之工作階段，亦會一併還原其圖層設定、重建圖與計數結果。
  \item \textbf{開啟參數視窗檢視預設值（非必要）：}若無特殊需求，可直接沿用預設參數；如需調整，可切換至\textbf{演算法} (Algorithm) 分頁並點擊\textbf{參數} (Parameters) 按鈕（詳見第~\ref{sec:tool-params}~節）。
  \item \textbf{執行管線：}於\textbf{演算法}分頁點擊\textbf{全部執行} (Run All) 按鈕，後端會依序執行\textbf{感興趣區域} (ROI Mask)、\textbf{前處理} (Preprocess)、\textbf{重建} (Reconstruct) 三階段（第~\ref{sec:tool-pipeline}~節），並於重建完成後\textbf{自動計數}；完成後畫布上即呈現重建圖，頂部工具列之\textbf{有效神經纖維數} (Effective Nerve Fibers) 欄位即顯示計數結果。
  \item \textbf{重建結果修改（非必要）：}若自動重建之結果與專家判讀有出入，可於頂部工具列切換成\textbf{纖維編輯} (Fiber Edit) 模式，於畫布上新增、刪除節點與邊以修整圖（第~\ref{sec:tool-edit}~節）。
  \item \textbf{遮罩修改（非必要）：}若樣本之表皮遮罩或纖維微粒遮罩本身有誤，可於頂部工具列切換成\textbf{表皮編輯} (Epidermis Edit) 或\textbf{纖維微粒編輯} (Particle Edit) 模式，於畫布上直接塗改\textbf{表皮遮罩} (Epidermis Mask) 與\textbf{纖維微粒遮罩} (Particle Mask)。惟此二遮罩為管線之\textbf{輸入}，修改後不會自動更新重建結果，須重新點擊\textbf{全部執行}重跑整個演算法，方能將變更反映於後續之重建與計數。
  \item \textbf{即時重新計數有效神經數量：}修整過程中無需手動觸發有效神經計數；本工具會於每次編輯後自動將當前修整後之圖送回後端重算，頂部工具列之有效神經纖維數與畫布上綠色有效邊即隨之同步更新（詳見第~\ref{subsec:count-current}~節）。
  \item \textbf{保存結果：}於\textbf{自動儲存} (Auto-save) 開啟時（預設），上述所有編輯之結果——包含修整後之重建圖、塗改後之遮罩與工作階段狀態——皆會自動寫回樣本資料夾，毋需任何存檔操作；若需將結果另存為指定檔名或輸出至他處，則使用\textbf{檔案}分頁之三個手動儲存按鈕（詳見第~\ref{sec:tool-io}~節）。
\end{enumerate}

後續各節依介面元素之分類詳述其全部選項與行為。

\section{側邊欄分頁}
\label{sec:tool-sidebar}

左側邊欄之全部控制依功能分為四個分頁，可由分頁列頂端切換：

\begin{itemize}
  \item \textbf{檔案 (Files)：}工作目錄選擇、樣本瀏覽與檔案儲存控制，為每次分析之起點（第~\ref{subsec:tool-samples}~節）。
  \item \textbf{圖層 (Layers)：}各影像圖層與重建圖之顯示控制（第~\ref{sec:tool-layers}~節）。
  \item \textbf{演算法 (Algorithm)：}AEL 管線之參數設定與階段執行（第~\ref{sec:tool-pipeline}~節）。
  \item \textbf{纖維 (Fibers)：}當前重建圖中每條纖維之長度列表與總長（第~\ref{sec:tool-fibers}~節）。
\end{itemize}

\noindent 四分頁之切換僅改變邊欄顯示之內容，不影響畫布狀態；以下四小節依序詳述之。

\subsection{檔案分頁}
\label{subsec:tool-samples}

檔案分頁負責指定資料來源、於樣本間切換，並集中所有檔案儲存之控制，其操作元件如下（如圖~\ref{fig:sample-tab} 所示）：

\begin{itemize}
  \item \textbf{選擇工作目錄 (Select Working Folder)：}點擊後開啟原生資料夾對話框，選定一存放待分析樣本之工作目錄。該目錄下之每個子資料夾視為一個樣本，其中依\textbf{檔名前綴}放置原始影像（\texttt{image}）、表皮遮罩（\texttt{epidermis}）與纖維微粒遮罩（\texttt{particle}）三張影像（支援 \texttt{png}、\texttt{jpg}、\texttt{tif}、\texttt{tiff}、\texttt{webp} 等格式）。選定後按鈕標籤改為\textbf{Change Working Folder}，其下並列出目錄之完整路徑與可用樣本數。所選工作目錄會被記憶，下次啟動時自動回復。
  \item \textbf{自動儲存切換鈕 (Auto-save)：}位於工作目錄區塊下方之總開關，控制本工具是否將編輯結果自動寫入磁碟（預設為\textbf{開啟}）。其狀態會被記憶，下次啟動時自動回復；所寫入之檔案與時機詳見第~\ref{subsec:io-autosave}~節。
  \item \textbf{手動儲存按鈕：}三個按鈕——\textbf{Save Epidermis Mask}、\textbf{Save Particle Mask} 與 \textbf{Save Fiber}——分別將表皮遮罩、纖維微粒遮罩與重建結果另存至指定檔名與資料夾。點擊後開啟儲存視窗（第~\ref{subsec:io-manual}~節），其行為\textbf{不受自動儲存開關影響}。
  \item \textbf{樣本清單：}以按鈕逐列列出目錄中所有可用樣本（依名稱排序）。點選任一樣本即自動載入其三張影像並設為作用中樣本（作用中者以藍色標示）；若某樣本缺少表皮遮罩或纖維微粒遮罩，其右側會顯示一警示圖示以提醒該樣本不完整。
\end{itemize}

\subsection{圖層分頁}
\label{sec:tool-layers}

圖層分頁列出畫布上之各影像圖層與重建圖並提供其顯示控制項。本分頁之控制項依圖層分為原始影像、灰階圖層與重建圖三組。

\subsubsection{原始影像圖層之控制}
\label{subsec:layer-original}

原始影像為所選樣本之 RGB 原始切片影像（於選定樣本時自動載入）。其控制元件（如圖~\ref{fig:layer-original} 所示）包含：

\begin{itemize}
  \item \textbf{圖層顯示切換鈕：} 位於原始影像標題列右側，以眼睛圖示表示，用以快速切換顯示／隱藏整個圖層。隱藏後其下方之顯色模式與透明度控制亦會一併摺起。
  \item \textbf{顯色模式 (Display Mode) 下拉選單：} 控制原始影像之顯色通道，可選之四種模式為：
    \begin{itemize}
      \item \textbf{紅色通道 (Red Channel)}：僅以紅色通道為強度。
      \item \textbf{綠色通道 (Green Channel)}（預設）：僅以綠色通道為強度，亦為 AEL 後端實際使用之輸入通道。
      \item \textbf{藍色通道 (Blue Channel)}：僅以藍色通道為強度。
      \item \textbf{強化綠色通道 (Green Viridis)}：以綠色通道為強度，再套用 Viridis 色階以增強對比，便於檢視纖維走向。
    \end{itemize}
    當選擇變更時畫布上之原始影像圖層會立即重新渲染。
  \item \textbf{透明度 (Opacity) 滑桿：} 範圍 $0\%$--$100\%$（預設 100\%），控制原始影像圖層之最終透明度。
\end{itemize}

\subsubsection{灰階圖層之共通控制}
\label{subsec:layer-masks}

\begin{itemize}
  \item \textbf{圖層顯示切換鈕：}以眼睛圖示表示，可快速切換顯示／隱藏整個圖層。
  \item \textbf{透明度滑桿：}範圍 $0\%$--$100\%$（預設 100\%），控制該層之最終透明度。
  \item \textbf{色彩選擇器 (Color)：}設定該層之染色。
\end{itemize}

\subsubsection{階段按鈕與啟用條件}
\label{subsec:stage-buttons}

三個階段按鈕依序排列並各自於右側顯示狀態圖示（圖~\ref{fig:tool-stage-status}）。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\linewidth]{figures/gui/stage_status.jpg}
  \caption[階段按鈕之狀態圖示]{階段按鈕之三種狀態圖示示例。圖中由上而下：感興趣區域為「完成」、前處理為「執行中」、重建為「待執行」。}
  \label{fig:tool-stage-status}

階段按鈕之啟用條件依序為：

\begin{enumerate}
  \item \textbf{感興趣區域 (ROI Mask)}：需已選取一含原始影像、表皮遮罩與纖維微粒遮罩之完整樣本。
  \item \textbf{前處理 (Preprocess)}：需感興趣區域階段狀態為「完成」。
  \item \textbf{重建 (Reconstruct)}：需前處理階段狀態為「完成」。重建完成後即產生新的重建圖，而計數會因偵測到重建圖之變動而自動執行（詳見第~\ref{subsec:count-current}~節），使用者無須另行觸發。
\end{enumerate}

當管線中任一階段處於執行中狀態時，所有階段按鈕與全部執行按鈕皆會暫時停用，避免發送出多筆請求。

\subsubsection{各階段之輸出}
\label{subsec:stage-output}

三階段對應之演算邏輯與輸出如下，與第~\ref{chap:method}~章之各節對應：

\begin{enumerate}
  \item \textbf{感興趣區域 (ROI Mask) 階段：} 對應第~\ref{subsec:roi}~節，於表皮遮罩上執行向下膨脹得 $M_{\text{ROI}}$，並於邊欄出現新的感興趣區域遮罩圖層控制。
  \item \textbf{前處理 (Preprocess) 階段：} 對應第~\ref{subsec:enhance}~節之完整影像增強鏈，依序執行綠色通道擷取、白色頂帽去背景、CLAHE 與多尺度 Sato 線狀結構濾波，並同步於後端計算下游重建階段所需之像素成本圖 $C$；前端則接收 Sato 響應圖並渲染於前處理結果圖圖層。
  \item \textbf{重建 (Reconstruct) 階段：} 對應第~\ref{sec:dijkstra}~節至第~\ref{sec:skeleton}~節之完整重建流程，將前處理之成本圖與纖維微粒標註轉為神經纖維之拓樸圖 $G_{\text{trim}}$，並以重建圖繪製於畫布上（各步驟細節詳見第~\ref{chap:method}~章）。此階段之執行會完整覆蓋畫布上既有之重建圖，若使用者於前次重建後曾手動編輯，該編輯不會被保留。
\end{enumerate}

\subsubsection{全部執行按鈕}
\label{subsec:run-all}

\textbf{全部執行}為一鍵串接執行「感興趣區域 $\to$ 前處理 $\to$ 重建」三階段之按鈕，並於重建完成後自動計數。全部執行之啟用條件為：已選取一完整樣本、且管線目前無任何階段處於執行中狀態。

\subsection{纖維分頁}
\label{sec:tool-fibers}

\textbf{纖維} (Fibers) 分頁列出當前重建圖中每一條獨立纖維之長度，由長至短排序，並於清單頂端顯示總長度。此清單之數據來源與第~\ref{subsec:count-current}~節所述之\textbf{自動計數}共用同一次後端運算：計數階段於回傳有效跨越數之同時，另按連通分量逐一回報其子樹統計（子樹編號、節點數、邊數與總長度），並於重建圖之每條邊上標註其所屬子樹編號。前端據此將長度列表與畫布上每條邊之歸屬同步呈現，故\textbf{纖維分頁之內容隨自動計數一併更新}——無論是重建階段產生新圖、或使用者於纖維編輯模式下增刪節點與邊，長度列表皆會與有效神經纖維數同步重新整理。

\paragraph{單位換算：} 各纖維長度預設以\textbf{微米 ($\mu$m)} 顯示，換算方式為將像素長度乘以該樣本之像素物理比例（$\mu\text{m} = \text{px} \times \text{ratio}$）；比例值讀取自工作目錄下之 \texttt{px\_um.json}，以樣本資料夾名稱為鍵值查詢。若該樣本於此設定檔中查無對應比例，則長度改以\textbf{像素 (px)} 顯示，並於分頁標題列以\textbf{橘色}文字標示 \texttt{(px)} 提示使用者當前顯示之數值尚未換算為物理單位。

\subsection{纖維選取與提示}
\label{subsec:fiber-highlight}

在纖維分頁點擊清單中之任一纖維項目，或於\textbf{檢視／平移}模式下直接點擊畫布上屬於某條纖維之任一線段，皆可將該纖維設為\textbf{選取狀態}，觸發以下提示效果：

\begin{itemize}
  \item 該纖維之所有邊變為粉紅色並加粗（見第~\ref{subsec:graph-render}~節之邊顏色）。

  \item 反之，若選取係由畫布點擊觸發，纖維分頁中對應之清單項目會自動捲動至可視範圍內，便於使用者確認所點選之纖維與長度數值。

\subsection{圖層上色機制}
\label{subsec:tinted-mask}

除原始影像與重建圖之外，其餘四層——表皮遮罩、感興趣區域遮罩、前處理結果圖與纖維微粒遮罩——皆為\textbf{灰階圖層}，套用同一套\textbf{灰階上色}機制：以影像亮度作為透明度、再於其上覆蓋使用者選定之純色，故越亮處顏色越飽和（完全不透明）、越暗處越接近透明。其中三張二值遮罩（表皮遮罩、感興趣區域遮罩、纖維微粒遮罩）為特例，白色像素完全染色、黑色像素完全透明；連續灰階之前處理結果圖（Sato 響應圖）則纖維響應愈強之像素愈接近飽和色、背景保持透明。每層之透明度滑桿再進一步調整整層之最終透明度。

原始影像不套用上述染色，而是依\textbf{顯色模式}（見第~\ref{subsec:layer-original}~節）擷取指定通道之亮度呈現；重建圖之配色另見第~\ref{subsec:graph-render}~節。

\subsection{重建圖之繪製}
\label{subsec:graph-render}

重建圖繪製於所有影像圖層之上，其內容為當前拓樸圖之節點（圓點）與邊（線段／折線）。其各項視覺屬性如下：

\begin{itemize}
  \item \textbf{節點顏色}（依節點於重建圖中之\textbf{度數} (degree) 決定）：
    \begin{itemize}
      \item 紅色 \texttt{\#EF4444}：度數為 $1$ 之節點（\textbf{端點}）。
      \item 藍色 \texttt{\#60A5FA}：度數為 $3$ 以上之節點（\textbf{分支點}）。
      \item 灰色：度數為 $2$ 之節點（路徑中繼點）。
      \item 黃色 \texttt{\#FCD34D}：當前\textbf{活躍鏈式起點}（編輯模式下之核心狀態，詳見第~\ref{subsec:edit-create}~節），優先於上述依度數之配色。
      \item \textbf{琥珀色外環、放大半徑}：被使用者選取之節點（待執行刪除或檢視之對象）。此狀態原以紅色實心標示，惟因與度數為 $1$ 之端點同色而易生混淆，故改以外環搭配放大節點半徑呈現，與填色區分。
    \end{itemize}
  \item \textbf{邊顏色}：
    \begin{itemize}
      \item 藍色 \texttt{\#3B82F6}：一般邊。
      \item 綠色 \texttt{\#34D399}：經計數階段判定為\textbf{有效跨越段}之邊（對應第~\ref{sec:crossing}~節之 $N_{\text{pred}}$ 之構成）。
      \item 黃色 \texttt{\#FCD34D}：被使用者點選之邊（編輯模式下之選取狀態）。
      \item 粉紅色：屬於當前被選取纖維（子樹）之所有邊，由纖維分頁或畫布點選觸發（見第~\ref{subsec:fiber-highlight}~節）。
    \end{itemize}
  \item \textbf{邊之幾何形式}：由重建／計數階段傳回之邊，若含有像素層之軌跡，則以\textbf{折線}沿該像素軌跡繪製，呈現多源區域擴張所回溯之實際路徑，否則（如使用者於編輯模式下手動新增之邊）以兩端節點之直線連接。
\end{itemize}

\subsection{平移、縮放與適配視野}
\label{subsec:tool-viewport}

無論處於何種互動模式，畫布皆支援以下視野操作：

\begin{itemize}
  \item \textbf{平移}：於檢視／平移模式下，按住滑鼠\textbf{左鍵}拖曳即可平移；於任意模式下，\textbf{中鍵}拖曳、\texttt{Shift} + 左鍵拖曳、或 \texttt{Ctrl} + 左鍵拖曳亦可平移。
  \item \textbf{縮放}：滑鼠滾輪。縮放會\textbf{以游標當前位置為中心}進行，便於對特定區域逐步放大檢視。縮放比例之上下限為 $0.1\times$ 至 $10\times$。
  \item \textbf{自動適配視野 (fit-to-view)}：當載入新樣本之原始影像時，畫布會自動依容器尺寸計算最大可顯示縮放比例（保留約 $24\,\text{像素}$邊距）並將影像置中。
\end{itemize}

\section{頂部工具列}
\label{sec:tool-toolbar}

頂部工具列橫跨主視窗頂端，由左至右包含：四個\textbf{互動模式}切換按鈕、兩項當前樣本之讀數（有效神經纖維數與影像尺寸）、一個\textbf{自動儲存狀態指示器}、當前重建圖之節點與邊計數，以及一个\textbf{清除}按鈕。模式切換按鈕之行為詳見第~\ref{sec:tool-modes}~節、清除按鈕詳見第~\ref{subsec:edit-clear}~節；本節說明工具列之兩項讀數、自動儲存指示器，及讀數背後之自動計數。

\subsection{有效神經纖維數與自動計數}
\label{subsec:count-current}

工具列之\textbf{有效神經纖維數} (Effective Nerve Fibers) 欄位顯示最近一次計數之 $N_{\text{pred}}$（如圖~\ref{fig:count-badge} 所示）。此計數\textbf{不設獨立按鈕、亦非管線階段}，而是由前端持續監看畫布上之重建圖：凡重建圖發生變動——無論是重建階段產生之新圖，或使用者於纖維編輯模式下增刪節點與邊——本工具即自動將\textbf{當前畫布上之重建圖}送回後端計數，該欄位之數值與畫布上綠色有效神經纖維邊隨之同步更新。為避免連續編輯期間發出過多請求，計數採短暫去抖動：一連串編輯僅於停止後觸發一次，且恆以最新之圖為準。

\subsection{影像尺寸}
\label{subsec:toolbar-imagesize}

\textbf{影像尺寸} (Image Size) 欄位顯示當前原始影像之原生像素尺寸（寬 $\times$ 高），供使用者確認載入切片之解析度；此尺寸亦為重建圖遮罩寫出時之光柵化解析度（見第~\ref{subsec:io-fibermask}~節）。

\subsection{自動儲存狀態指示器}
\label{subsec:toolbar-autosave}

工具列並顯示一\textbf{自動儲存狀態指示器}，以磁片圖示搭配文字標示當前之寫檔狀態：開啟時為綠色之 \textbf{Auto-save On}、關閉時為灰色之 \textbf{Auto-save Off}。此指示器\textbf{僅供顯示}，其切換須至\textbf{檔案}分頁之自動儲存切換鈕（第~\ref{subsec:tool-samples}~節）；置於工具列之目的在於使用者於畫布上長時間編輯時，得隨時確認其修整是否正被寫回磁碟，避免誤以為已保存。

\section{互動模式}
\label{sec:tool-modes}

本工具之畫布提供四種互動模式，可由頂部工具列之四個按鈕切換（如圖~\ref{fig:tool-mode-switch} 所示）：

\begin{itemize}
  \item \textbf{檢視／平移 (View / Pan) 模式}：指標圖示，深灰色背景表示啟用，為預設模式；所有滑鼠左鍵拖曳皆視為平移，點擊空白處不會建立節點，可安全瀏覽影像而不致誤觸圖形。此模式下直接點擊畫布上屬於某條纖維之線段，可選取並提示該纖維（見第~\ref{subsec:fiber-highlight}~節），且不會與平移操作互相誤觸。
  \item \textbf{纖維編輯 (Fiber Edit) 模式}：鉛筆圖示，藍色背景表示啟用，開啟重建圖之全部編輯互動（新增、刪除節點與邊，詳見第~\ref{sec:tool-edit}~節）。啟用時畫布頂端中央會浮現藍色提示「Fiber edit — click to add nodes」；若此時重建圖圖層被隱藏，則改顯示橘色提示，須先開啟該圖層方能編輯。
  \item \textbf{纖維微粒編輯 (Particle Edit) 模式}：筆刷圖示，綠色背景表示啟用，用於在畫布上直接塗改纖維微粒遮罩。啟用時畫面僅保留原始影像與纖維微粒遮罩兩層以利對位；左鍵塗畫、右鍵開啟筆刷／橡皮擦與筆刷大小之選單。
  \item \textbf{表皮編輯 (Epidermis Edit) 模式}：刷子圖示，青色背景表示啟用，操作方式與纖維微粒編輯相同，惟編輯對象為表皮遮罩，且啟用時畫面僅保留原始影像與表皮遮罩兩層。
\end{itemize}

\noindent \textbf{纖維微粒編輯}與\textbf{表皮編輯}兩模式之詳細塗改操作見第~\ref{sec:tool-paint}~節；其所塗改之遮罩於自動儲存開啟時會寫回該樣本之來源檔，且無論是否寫檔皆作為管線之輸入，故修改後須重新執行管線方能反映於重建與計數（見第~\ref{sec:tool-workflow}~節）。

\section{圖形編輯操作}
\label{sec:tool-edit}

進入\textbf{纖維編輯}模式後，使用者可於重建圖上進行節點與邊之新增、選取、刪除等互動。本節逐項列出全部編輯操作。

\subsection{節點與邊之新增}
\label{subsec:edit-create}

本工具之圖形編輯採用\textbf{鏈式}模式：所有節點與邊之新增皆以「選中之節點」此一狀態為核心，同一時間下只存在一個被選中的節點，圍繞其\textbf{產生、延伸、結束}三個階段進行。當存在已選擇之節點時，下一次互動會以該節點為基礎延伸出邊；反之則僅進行單純之建立或選取。實際之滑鼠操作可歸納為\textbf{左鍵點空白處}與\textbf{左鍵點現有節點}兩類，各自於當前有／無選中節點時行為略異：

\begin{enumerate}
  \item \textbf{左鍵點空白處：}
  \begin{enumerate}
    \item \textit{無選中節點時：}於游標位置建立一個新節點，並選中該節點（鏈式之\textbf{產生}）。
    \item \textit{已有選中節點時：}於游標位置建立一個新節點，並以一條新邊將其與當前選中之節點相連，然後轉換選擇新建立之節點（鏈式之\textbf{延伸}）。
  \end{enumerate}

  \item \textbf{左鍵點現有節點：}
  \begin{enumerate}
    \item \textit{無選中節點時：}將被點擊之節點設為選中節點，畫面上不新增節點或邊（亦屬\textbf{產生}，惟起點為既有節點）。
    \item \textit{已有選中節點時：}若被點擊之節點與選中節點不同，且兩者之間尚無邊，則建立一條新邊將兩者相連（重複之邊不會被加入）；無論是否新增邊，被點擊之節點都會被設為新的選中節點（亦屬\textbf{延伸}，惟端點為既有節點）。
  \end{enumerate}
\end{enumerate}

\paragraph{延伸過程之預覽：}若有選中節點時，畫面會即時繪製一條由活躍起點延伸至當前滑鼠位置之淺藍色虛線，作為下一條邊之預覽。此預覽僅為視覺輔助，實際之邊建立仍需於游標位置觸發一次左鍵點擊方會發生。

\paragraph{結束當前鏈式：}當不再需要延伸當前鏈式時，可藉由下列任一操作將節點取消選中、結束鏈式：

\begin{itemize}
  \item 右鍵點擊畫布任意位置。
  \item 按下 \texttt{Esc} 鍵。
\end{itemize}

\noindent 結束後，下一次左鍵點擊將以「無選中節點」之狀態重新進入產生階段。


\subsection{選取}
\label{subsec:edit-select}

於編輯模式下：

\begin{itemize}
  \item \textbf{左鍵點邊}：將該邊設為選中狀態，邊色變為黃色 \texttt{\#FCD34D}、線寬加粗。
  \item \textbf{左鍵點節點}：將該節點同時設為「活躍鏈式起點」並清空原有選取（被點之節點變黃 \texttt{\#FCD34D}，惟鏈式操作優先於選取）。
  \item \textbf{右鍵點邊或節點}：將該元素設為選中狀態，並於滑鼠位置開啟選單（詳見第~\ref{subsec:edit-context-menu}~節）。
\end{itemize}

\noindent 按下 \texttt{Esc} 將同時清空當前選中、活躍鏈式起點與選單。

\subsection{刪除}
\label{subsec:edit-delete}
  
可透過下列任一方式刪除被選中之元素：

\begin{itemize}
  \item \textbf{按下 \texttt{Del} 或 \texttt{Backspace} 鍵：} 若有選中節點則刪除節點（連同所有與其相連之邊），否則刪除選中邊。
  \item \textbf{右鍵 → 選單：} 詳見下節。
\end{itemize}

刪除邊時，只要因該刪除而\textbf{變為孤立（不再與任何邊相連）之節點，會被自動清除}；此設計避免畫布上累積無意義之孤點。刪節點時則直接連同所有與其相鄰之邊一併移除，並且若被刪節點為當前鏈式之活躍起點，活躍狀態亦會被清空。

\subsection{右鍵選單}
\label{subsec:edit-context-menu}

於編輯模式下右鍵點擊邊或節點，會在滑鼠位置浮現一個固定定位之選單，對於不同物件有不同內容（如圖~\ref{fig:edit-context-menu} 所示）：

\begin{itemize}
  \item \textbf{邊}：選單含一項\textbf{刪除邊 (Delete Edge)}（右側標示快捷鍵 \texttt{Del}）。
  \item \textbf{節點}：選單含一項\textbf{刪除節點 (Delete Node)}（右側標示快捷鍵 \texttt{Del}）。
\end{itemize}

點擊選單項目即執行對應之刪除；點擊選單外或按 \texttt{Esc} 即關閉選單而不執行任何動作。選單之背景與邊框採與其他介面元素一致之深色主題。

\subsection{清除}
\label{subsec:edit-clear}

頂部工具列右側之紅色圖示按鈕為\textbf{清除}（清空重建圖）。點擊後跳出一個確認對話框「確定要清除所有節點與邊嗎？」（Clear all nodes and edges?），確認後清空重建圖之所有節點與邊；取消則無任何效果。此按鈕不受編輯／檢視模式影響，於任一模式下皆可使用。

\subsection{編輯後重新計數}
\label{subsec:edit-recount}

完成圖形編輯後，本工具會\textbf{自動}將當前（含編輯之）重建圖送回後端重新計數，無須手動觸發（其運作原理詳見第~\ref{subsec:count-current}~節）。

\section{遮罩塗改操作}
\label{sec:tool-paint}

於\textbf{纖維微粒編輯}或\textbf{表皮編輯}模式下（第~\ref{sec:tool-modes}~節），使用者可直接於畫布上以筆刷塗改對應之遮罩，用以修正染色不全或標註有誤之處。兩模式之操作完全相同，僅塗改對象不同：纖維微粒編輯改動纖維微粒遮罩、表皮編輯改動表皮遮罩。進入該模式時，畫面僅保留原始影像與被編輯之遮罩兩層以利對位。

\begin{itemize}
  \item \textbf{塗畫：}以滑鼠左鍵於畫布上點按可塗上一圓形筆觸，按住左鍵拖曳則沿游標軌跡連續塗畫。\textbf{筆刷} (Brush) 於遮罩上塗白（納入該區）、\textbf{橡皮擦} (Erase) 塗黑（自遮罩移除）。
  \item \textbf{筆刷指示環：}游標處恆繪製一同心圓指示環，其直徑即當前筆刷直徑；內圈為綠色表示筆刷、紅色表示橡皮擦，便於下筆前預覽塗改範圍。
  \item \textbf{工具選單：}於畫布上按滑鼠\textbf{右鍵}開啟工具選單（如圖~\ref{fig:paint-menu} 所示），可切換\textbf{筆刷}／\textbf{橡皮擦}，並以滑桿設定筆刷直徑（範圍 $1$--$100$ 像素，預設 $5$ 像素）。調整滑桿不會關閉選單；點擊工具按鈕或畫布空白處則關閉之。
\end{itemize}

\section{檔案儲存與結果輸出}
\label{sec:tool-io}

本工具之寫檔行為分為兩條互補之路徑：\textbf{自動儲存}於每次編輯後，將結果直接寫入該樣本自身之資料夾，不另行詢問檔名或位置——新產生之專案檔與纖維遮罩若已存在則直接覆蓋，塗改後之遮罩亦直接覆寫其來源檔；\textbf{手動儲存}則供使用者將特定產物以指定檔名另存至任意位置，作為結果之輸出與交付。二者之控制項皆集中於側邊欄之\textbf{檔案}分頁（第~\ref{subsec:tool-samples}~節），本節說明其語意：何者被寫入、於何時、以何檔名。

\subsection{自動儲存}
\label{subsec:io-autosave}

自動儲存使用一開關控制，預設開啟，其狀態記憶於本機並於下次啟動時回復。開啟時，本工具會於作用中樣本之資料夾內自動寫入下列三類檔案，同名檔案一律直接覆蓋：

\begin{enumerate}
  \item \textbf{專案檔 \texttt{fibertrace\_project.json}：}記錄整個工作階段——圖層設定、重建圖之節點與邊、演算法參數、各階段狀態與有效跨越數——並於下次選取同一樣本時自動還原。
  \item \textbf{纖維遮罩 \texttt{fibertrace\_mask.png}：}與專案檔同步寫出之當前重建圖\textbf{二元遮罩影像}，其光柵化方式見第~\ref{subsec:io-fibermask}~節。
  \item \textbf{來源遮罩檔：}於纖維微粒編輯或表皮編輯模式下之塗改結果，直接覆寫該樣本之表皮遮罩或纖維微粒遮罩原檔（第~\ref{sec:tool-paint}~節）。
\end{enumerate}

關閉自動儲存時，\textbf{上述三類寫入全數停止}：專案檔與纖維遮罩不再產生，塗改亦僅存在於畫面與當前工作階段中，磁碟上之來源遮罩檔保持原狀。此模式適用於僅欲檢視或試驗性調整、而不希望更動原始資料之情境；惟此時若切換樣本或關閉應用程式，未經手動儲存之編輯將\textbf{不予保留}。頂部工具列之狀態指示器（第~\ref{subsec:toolbar-autosave}~節）即為此設計之安全提示。

\label{subsec:io-manual}

\subsection{重建圖之遮罩光柵化}
\label{subsec:io-fibermask}

自動儲存之 \texttt{fibertrace\_mask.png} 與手動儲存之 $\langle\text{name}\rangle$\texttt{\_mask.png} 皆為當前重建圖之\textbf{二元遮罩影像}（PNG），其產生方式相同：以黑色為背景、白色沿各邊之像素軌跡繪製纖維線條（線寬 $1$ 像素），並依原始影像之原生解析度（見第~\ref{subsec:toolbar-imagesize}~節）光柵化，使輸出之遮罩與原切片\textbf{像素對齊}。此遮罩可作為重建結果之存檔，亦可供下游之像素級分析（如與專家標註比對）使用。
