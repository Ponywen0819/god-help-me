\chapter{視覺化神經纖維分析工具}
\label{chap:tool}

為使第~\ref{chap:method}~章所述之 AEL 演算法得以互動執行、視覺檢驗、並進一步支援使用者於重建結果上手動修整再重新計數，本研究實作了一套桌面端之圖形使用者介面工具（以下簡稱\textbf{本工具}）。本章依序介紹設計動機、執行環境與系統架構、介面布局、典型工作流、影像圖層、管線執行、參數設定、互動模式、圖形編輯、結果輸出與專案儲存，以及操作速查表。

\section{設計動機}
\label{sec:tool-overview}

第~\ref{chap:method}~章之 AEL 雖為一全自動之演算法流程，於臨床導入時仍存在三項實務需求，使一個專屬之操作介面有其必要：

\begin{enumerate}
  \item \textbf{中介產物之視覺檢驗：} AEL 之輸出為一純量計數 $N_{\text{pred}}$，但其品質高度依賴前處理、成本圖與多源擴張等中介結果之合理性；臨床端使用者需能即時觀察各階段之輸出疊合於原始影像上，以判斷個別參數設定是否合理。
  \item \textbf{人為修整之回饋迴圈：} 於染色嚴重斷裂或微粒標註本身有誤之切片上，自動重建之結果未必能完全符合專家判讀；使用者需能於重建後直接在影像上新增、刪除節點與邊，並以修整後之拓樸\textbf{重新}進行有效跨越計數。
  \item \textbf{階段獨立執行與快取：} 由於 AEL 各階段之計算成本不一（其中 Sato 濾波與多源擴張最為耗時），使用者於探索參數時希望僅重跑受影響之階段而非整條管線；下游階段亦應能直接套用上游之快取結果而毋需重新計算。
\end{enumerate}

本工具即針對此三項需求設計：以多圖層疊合呈現中介產物、提供互動式圖形編輯與重新計數、並以階段化之管線執行配合後端快取支援增量重算。

\section{執行環境與系統架構}
\label{sec:tool-arch}

本工具為一跨平台之桌面應用程式，以 Electron 框架建構，可於 Windows、macOS 與 Linux 上執行。其使用者介面負責影像圖層之疊合呈現與互動式圖形編輯，而第~\ref{chap:method}~章所述之 AEL 演算法則以 Python 實作並作為後端運算核心。本工具之後端於 Python 3.10 環境下開發，故執行時須具備 Python 3.10 以上之環境。

\section{介面布局}
\label{sec:tool-layout}

本工具之主視窗分為三大區塊（圖~\ref{fig:tool-layout}）：

\begin{enumerate}
  \item \textbf{左側邊欄 (Sidebar)：} 上半為影像圖層管理（第~\ref{sec:tool-layers}~節），下半為 AEL 管線控制（第~\ref{sec:tool-pipeline}~節）；最下方另含一段操作說明文字。

\section{典型工作流程}
\label{sec:tool-workflow}

第一次使用本工具者，可依下列五步完成「載入 → 自動計數 → 人工修整 → 重新計數」之完整流程：

\begin{enumerate}
  \item \textbf{上傳三張影像：}於左側邊欄上半之圖層管理區，依序點擊\textbf{原始影像}、\textbf{表皮遮罩}、\textbf{纖維微粒遮罩}三層之上傳按鈕（\textbf{Upload Original / Mask / Annotation}），分別載入該切片之 RGB 原始影像、表皮二值遮罩與纖維微粒標註遮罩。
  \item \textbf{開啟參數視窗檢視預設值（非必要）：}若無特殊需求，可直接沿用預設參數；如需調整，可於管線區塊頂部點擊\textbf{參數} (Parameters) 按鈕（詳見第~\ref{sec:tool-params}~節）。
  \item \textbf{執行管線：}點擊邊欄下半之\textbf{全部執行} (Run All) 按鈕，後端會依序執行\textbf{感興趣區域} (ROI Mask)、\textbf{前處理} (Preprocess)、\textbf{重建} (Reconstruct)、\textbf{計數} (Count) 四階段（第~\ref{sec:tool-pipeline}~節）；完成後畫布上即呈現重建圖，左上角顯示有效跨越數。
  \item \textbf{人工修整（非必要）：}若自動重建之結果與專家判讀有出入，可切換至\textbf{編輯圖}模式（頂部工具列），於畫布上新增、刪除節點與邊以修整圖（第~\ref{sec:tool-edit}~節）。
  \item \textbf{重新計數：}修整完畢後，於管線區塊單獨點擊\textbf{計數}按鈕，即可將當前修整後之圖送回後端重新計數，左上角資訊框與綠色有效跨越邊會同步更新（詳見第~\ref{subsec:count-current}~節）。
\end{enumerate}

後續各節依介面元素之分類詳述其全部選項與行為。

\subsection{二值影像之上色機制}
\label{subsec:tinted-mask}

除原始影像與重建圖之外，\textbf{表皮遮罩、感興趣區域遮罩、前處理結果圖、纖維微粒遮罩四層皆採同一套上色機制}：以原圖之亮度作為透明度遮罩、再於其上覆蓋使用者指定之純色。其效果為：影像越亮處顏色越飽和（完全不透明）、影像越暗處越接近完全透明。對二值之遮罩而言，白色像素被完全染上選定顏色、黑色像素則完全透明；對連續灰階之前處理結果圖（Sato 響應圖）而言，纖維響應愈強之像素愈接近飽和色、背景則保持透明。每層之透明度滑桿則進一步控制整層之最終透明度。

\subsection{原始影像圖層}
\label{subsec:layer-original}

原始影像為使用者上傳之 RGB 原始切片影像。其控制元件（如圖~\ref{fig:layer-original} 所示）包含：

\begin{itemize}
  \item \textbf{上傳／替換按鈕（Upload / Change Original）：} 標籤於上傳前為「Upload Original」、上傳後切換為「Change Original」；點擊後開啟原生檔案對話框，支援 \texttt{png}、\texttt{jpg}、\texttt{tif}、\texttt{tiff}、\texttt{webp} 等格式。首次上傳完成後，畫布會自動執行放大率與位置之調整，依容器尺寸與影像原始尺寸計算最大可顯示縮放比例，並將影像置中。
  \item \textbf{圖層顯示切換鈕：} 位於原始影像標題列右側，以眼睛圖示表示，用以快速切換顯示／隱藏整個圖層。隱藏後其下方之顯色模式與透明度控制亦會一併摺起。
  \item \textbf{顯色模式 (Display Mode) 下拉選單：} 控制原始影像之顯色通道，可選之四種模式為：
    \begin{itemize}
      \item \textbf{紅色通道 (Red Channel)}：僅以紅色通道為強度。
      \item \textbf{綠色通道 (Green Channel)}（預設）：僅以綠色通道為強度，亦為 AEL 後端實際使用之輸入通道。
      \item \textbf{藍色通道 (Blue Channel)}：僅以藍色通道為強度。
      \item \textbf{強化綠色通道 (Green Viridis)}：以綠色通道為強度，再套用 Viridis 色階以增強對比，便於檢視纖維走向。
    \end{itemize}
    當選擇變更時畫布上之原始影像圖層會立即重新渲染。
  \item \textbf{透明度 (Opacity) 滑桿：} 範圍 $0\%$--$100\%$（預設 100\%），控制原始影像圖層之最終透明度。
\end{itemize}

\subsection{遮罩類圖層之共通控制}
\label{subsec:layer-masks}

除原始影像之外，餘下之表皮遮罩、感興趣區域遮罩、前處理結果圖、纖維微粒遮罩四層皆套用同一套上色機制（第~\ref{subsec:tinted-mask}~節），並共用同一組控制元件（如圖~\ref{fig:layer-masks} 所示）：

\begin{itemize}
  \item \textbf{圖層顯示切換鈕：}以眼睛圖示表示，可快速切換顯示／隱藏整個圖層。
  \item \textbf{透明度滑桿：}範圍 $0\%$--$100\%$（預設 100\%），控制該層之最終透明度。
  \item \textbf{色彩選擇器 (Color)：}HTML 原生色彩控制項，設定該層之染色（即上色機制中所覆蓋之純色）。

\end{itemize}

\subsection{重建圖圖層}
\label{subsec:layer-graph}

重建圖繪製於所有影像圖層之上，其內容為當前拓樸圖之節點（圓點）與邊（線段／折線）。其各項視覺屬性如下：

\begin{itemize}
  \item \textbf{節點顏色}：
    \begin{itemize}
      \item 藍色 \texttt{\#60A5FA}：一般節點（無特殊狀態）。
      \item 黃色 \texttt{\#FCD34D}：當前\textbf{活躍鏈式起點}（編輯模式下之核心狀態，詳見第~\ref{subsec:edit-create}~節）。
      \item 紅色 \texttt{\#EF4444}：被使用者點選之節點（待執行刪除或檢視之對象）。
    \end{itemize}
  \item \textbf{邊顏色}：
    \begin{itemize}
      \item 藍色 \texttt{\#3B82F6}：一般邊。
      \item 綠色 \texttt{\#34D399}：經計數階段判定為\textbf{有效跨越段}之邊（對應第~\ref{sec:crossing}~節之 $N_{\text{pred}}$ 之構成）。
      \item 黃色 \texttt{\#FCD34D}：被使用者點選之邊。
    \end{itemize}
  \item \textbf{邊之幾何形式}：由重建／計數階段傳回之邊，若含有像素層之軌跡，則以\textbf{折線}沿該像素軌跡繪製，忠實呈現多源區域擴張所回溯之實際路徑；否則（如使用者於編輯模式下手動新增之邊）以兩端節點之直線連接。
\end{itemize}

重建圖亦具有獨立之顯示／隱藏切換鈕（如圖~\ref{fig:layer-graph} 所示），可如其他圖層般快速切換其顯示；惟其不參與透明度控制。作為演算法輸出與使用者編輯之主要呈現載體，重建圖預設為顯示。

\section{管線階段執行}
\label{sec:tool-pipeline}

邊欄下半部之\textbf{神經管線} (Neural Pipeline) 區塊為 AEL 之四階段控制台，包含一個\textbf{參數}按鈕、四個階段按鈕（\textbf{感興趣區域}、\textbf{前處理}、\textbf{重建}、\textbf{計數}）、與一個\textbf{全部執行}按鈕。

\subsection{階段按鈕與啟用條件}
\label{subsec:stage-buttons}

四個階段按鈕依序排列並各自於右側顯示狀態圖示（圖~\ref{fig:tool-stage-status}）。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.5\linewidth]{figures/gui_stage_status.png}
  \caption[階段按鈕之狀態圖示]{階段按鈕之三種狀態圖示示例。圖中由上而下：感興趣區域為「完成」、前處理為「執行中」、重建與計數為「待執行」。}
  \label{fig:tool-stage-status}
\end{figure}

階段按鈕之啟用條件依序為：

\begin{enumerate}
  \item \textbf{感興趣區域 (ROI Mask)}：需原始影像、表皮遮罩、纖維微粒遮罩三張影像皆已上傳。
  \item \textbf{前處理 (Preprocess)}：需感興趣區域階段狀態為「完成」。
  \item \textbf{重建 (Reconstruct)}：需前處理階段狀態為「完成」。重建按鈕\textbf{自動鏈接}至計數階段，其完成後會立即觸發一次計數，使用者於此情境下無須另行按下計數按鈕。
  \item \textbf{計數 (Count)}：需重建階段狀態為「完成」（即作業內已有重建圖）。此按鈕之特殊性在於：其執行對象\textbf{永遠為當下畫布上之重建圖}，包含使用者於重建後手動編輯之版本（詳見第~\ref{subsec:count-current}~節）。
\end{enumerate}

當管線中任一階段處於執行中狀態時，所有階段按鈕與全部執行按鈕皆會暫時停用，避免發送出多筆請求。

\subsection{各階段之輸出}
\label{subsec:stage-output}

四階段對應之演算邏輯與輸出如下，與第~\ref{chap:method}~章之各節對應：

\begin{enumerate}
  \item \textbf{感興趣區域 (ROI Mask) 階段：} 對應第~\ref{subsec:roi}~節，於表皮遮罩上執行向下膨脹得 $M_{\text{ROI}}$，並於邊欄出現新的感興趣區域遮罩圖層控制。
  \item \textbf{前處理 (Preprocess) 階段：} 對應第~\ref{subsec:enhance}~節之完整影像增強鏈，依序執行綠色通道擷取、白色頂帽去背景、CLAHE 與多尺度 Sato 線狀結構濾波，並同步於後端計算下游重建階段所需之像素成本圖 $C$；前端則接收 Sato 響應圖並渲染於前處理結果圖圖層。
  \item \textbf{重建 (Reconstruct) 階段：} 對應第~\ref{sec:dijkstra}~節至第~\ref{sec:skeleton}~節，執行多源 Dijkstra 擴張、相遇點偵測、元件層圖建立、閾值裁剪、最小生成森林、橋接遮罩、Zhang--Suen 骨架化、分段偵測與短樁修剪，最終得 $G_{\text{trim}}$，並以重建圖繪製於畫布上。\textbf{此階段之執行會完整覆蓋畫布上既有之重建圖}；若使用者於前次重建後曾手動編輯，該編輯不會被保留。
  \item \textbf{計數 (Count) 階段：} 對應第~\ref{sec:crossing}~節，依當前圖之纖維涵蓋篩選、區域標記與線段層之有效跨越判定，輸出 $N_{\text{pred}}$。完成後：
    \begin{itemize}
      \item 畫布左上角浮現一資訊框，以「\textbf{Effective Crossings}」（有效跨越數）為標題並顯示其數值 $N_{\text{pred}}$（如圖~\ref{fig:count-badge} 所示）。
      \item 被判定為有效跨越段之邊由藍色變為綠色（\texttt{\#34D399}）。
    \end{itemize}
\end{enumerate}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.3\linewidth]{figures/gui_crossing_count.png}
  \caption[計數結果之資訊框]{計數完成後於畫布左上角浮現之資訊框，標示「Effective Crossings」及其數值。}
  \label{fig:count-badge}
\end{figure}

\subsection{計數階段之對象}
\label{subsec:count-current}

計數階段之執行對象由前端決定，分為兩種情形：

\begin{itemize}
  \item \textbf{由重建階段自動鏈接而觸發之計數：} 計數對象為剛剛由重建階段產生之重建圖。此即「重建 → 自動計數」之預設流程。
  \item \textbf{使用者主動點擊計數按鈕：} 計數對象為\textbf{當下畫布上之重建圖}，含使用者所有手動編輯。
\end{itemize}

此設計使「重建 → 編輯 → 重新計數」之人機協同流程成為一階互動：使用者只需於完成自動重建後切入編輯模式、修整重建圖，再點一次計數，畫布上之有效跨越數與綠色邊即同步更新。

\subsection{全部執行按鈕}
\label{subsec:run-all}

\textbf{全部執行}為一鍵串接執行「感興趣區域 $\to$ 前處理 $\to$ 重建 $\to$ 計數」四階段之按鈕；任一階段失敗即停止後續執行，並於管線區塊下方之紅色錯誤框中顯示錯誤訊息。全部執行之啟用條件為：三張輸入影像皆已上傳、且管線目前無任何階段處於執行中狀態。

\section{圖形編輯操作}
\label{sec:tool-edit}

進入\textbf{編輯圖}模式後，使用者可於重建圖上進行節點與邊之新增、選取、刪除等互動。本節逐項列出全部編輯操作。

\subsection{節點與邊之新增}
\label{subsec:edit-create}

本工具之圖形編輯採用\textbf{鏈式}模式：所有節點與邊之新增皆以「選中之節點」此一狀態為核心，同一時間下只回存在一個被選中的節點，圍繞其\textbf{產生、延伸、結束}三個階段進行。當存在已選擇之節點時，下一次互動會以該節點為基礎延伸出邊；反之則僅進行單純之建立或選取。實際之滑鼠操作可歸納為\textbf{左鍵點空白處}與\textbf{左鍵點現有節點}兩類，各自於當前有／無選中節點時行為略異：

\begin{enumerate}
  \item \textbf{左鍵點空白處：}
  \begin{enumerate}
    \item \textit{無選中節點時：}於游標位置建立一個新節點，並選中該節點（鏈式之\textbf{產生}）。
    \item \textit{已有選中節點時：}於游標位置建立一個新節點，並以一條新邊將其與當前選中之節點相連，然後轉換選擇新建立之節點（鏈式之\textbf{延伸}）。
  \end{enumerate}

  \item \textbf{左鍵點現有節點：}
  \begin{enumerate}
    \item \textit{無選中節點時：}將被點擊之節點設為選中節點，畫面上不新增節點或邊（亦屬\textbf{產生}，惟起點為既有節點）。
    \item \textit{已有選中節點時：}若被點擊之節點與選中節點不同，且兩者之間尚無邊，則建立一條新邊將兩者相連（重複之邊不會被加入）；無論是否新增邊，被點擊之節點都會被設為新的選中節點（亦屬\textbf{延伸}，惟端點為既有節點）。
  \end{enumerate}
\end{enumerate}

\paragraph{延伸過程之預覽：}若有選中節點時，畫面會即時繪製一條由活躍起點延伸至當前滑鼠位置之淺藍色虛線，作為下一條邊之預覽。此預覽僅為視覺輔助，實際之邊建立仍需於游標位置觸發一次左鍵點擊方會發生。

\paragraph{結束當前鏈式：}當不再需要延伸當前鏈式時，可藉由下列任一操作將節點取消選中、結束鏈式：

\begin{itemize}
  \item 右鍵點擊畫布任意位置。
  \item 按下 \texttt{Esc} 鍵。
\end{itemize}

\noindent 結束後，下一次左鍵點擊將以「無選中節點」之狀態重新進入產生階段。


\subsection{選取}
\label{subsec:edit-select}

於編輯模式下：

\begin{itemize}
  \item \textbf{左鍵點邊}：將該邊設為選中狀態，邊色變為黃色 \texttt{\#FCD34D}、線寬加粗。
  \item \textbf{左鍵點節點}：將該節點同時設為「活躍鏈式起點」並清空原有選取（被點之節點變黃 \texttt{\#FCD34D}，惟鏈式操作優先於選取）。
  \item \textbf{右鍵點邊或節點}：將該元素設為選中狀態，並於滑鼠位置開啟選單（詳見第~\ref{subsec:edit-context-menu}~節）。
\end{itemize}

\noindent 按下 \texttt{Esc} 將同時清空當前選中、活躍鏈式起點與選單。

\subsection{刪除}
\label{subsec:edit-delete}
  
可透過下列任一方式刪除被選中之元素：

\begin{itemize}
  \item \textbf{按下 \texttt{Del} 或 \texttt{Backspace} 鍵。} 若有選中節點則刪除節點（連同所有與其相連之邊），否則刪除選中邊。
  \item \textbf{右鍵 → 選單。} 詳見下節。
\end{itemize}

刪邊時，凡因該刪除而\textbf{變為孤立（不再與任何邊相連）之節點，會被自動清除}；此設計避免畫布上累積無意義之孤點。刪節點時則直接連同所有與其相鄰之邊一併移除，並且若被刪節點為當前鏈式之活躍起點，活躍狀態亦會被清空。

\subsection{右鍵選單}
\label{subsec:edit-context-menu}

\begin{itemize}
  \item \textbf{邊}：選單含一項\textbf{刪除邊 (Delete Edge)}（右側標示快捷鍵 \texttt{Del}）。
  \item \textbf{節點}：選單含一項\textbf{刪除節點 (Delete Node)}（右側標示快捷鍵 \texttt{Del}）。

\section{結果輸出與專案儲存}
\label{sec:tool-io}

除即時之檢視與編輯外，本工具另提供三項與資料持久化相關之功能：將重建結果輸出為遮罩影像、將整個工作階段存為專案檔、以及自專案檔還原階段。其中遮罩輸出之按鈕位於左側邊欄之重建圖區塊，專案之儲存與載入按鈕則位於頂部工具列右側。

\paragraph{專案儲存（Save）：}頂部工具列右側之 \textbf{Save} 按鈕（與載入按鈕並列，如圖~\ref{fig:io-saveload} 所示）將整個工作階段序列化為單一\textbf{自含之專案檔}（副檔名 \texttt{.ntproj}）。其內容涵蓋原始影像、各衍生圖層（表皮遮罩、纖維微粒遮罩、感興趣區域遮罩、前處理結果圖）、圖層顯示設定、當前重建圖、演算法參數、各階段狀態與有效跨越數，專案檔可獨立攜帶而毋需外部相依檔案。預設檔名為 \texttt{neurotrace\_project.ntproj}。

\paragraph{專案載入（Load）：}頂部工具列右側之 \textbf{Load} 按鈕可開啟先前儲存之專案檔，完整還原上述工作階段——包含重建圖、圖層、圖層設定、演算法參數、各階段狀態與計數結果，使分析與修整得於不同時間或裝置上接續進行。
