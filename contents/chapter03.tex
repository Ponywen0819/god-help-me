\chapter{研究方法與設計}
\label{chap:method}

本章說明本研究所提出之\textbf{標註擴張連結} (Annotation Expansion Linker, AEL) 演算法之完整設計。給定一張 PGP 9.5 染色之皮膚切片影像 $I \in \mathbb{R}^{H \times W \times 3}$、表皮遮罩 $M \in \{0, 255\}^{H \times W}$、以及由人工初步標註所得之二值\textbf{纖維微粒} (particle)~\cite{hsueh2026machine} 標註 $A \in \{0, 255\}^{H \times W}$，AEL 之目標為輸出一個\textbf{像素級無向圖} $G_{\text{trim}} = (V_{\text{trim}}, E_{\text{trim}})$，其中 $V_{\text{trim}} \subseteq \mathbb{Z}^2$ 為骨架節點所對應之像素座標集合、$E_{\text{trim}}$ 為沿纖維之連線集合，並於其上計算有效跨越數 $N_{\text{cross}}$。以下各節依序詳述：第~\ref{sec:preprocessing}~節說明前處理與成本圖建構；第~\ref{sec:dijkstra}~節說明多源區域擴張；第~\ref{sec:component-graph}~節描述相遇點偵測與元件層圖之建立；第~\ref{sec:prune-mst}~節說明成本裁剪與最小生成森林；第~\ref{sec:skeleton}~節說明像素級拓樸之建構；最後第~\ref{sec:crossing}~節說明於該拓樸上進行有效跨越計數之完整程序。

\section{前處理與成本圖建構}
\label{sec:preprocessing}

\subsection{感興趣區域之建立}
\label{subsec:roi}

依 EFNS／PNS 計數規範~\cite{jointtaskforce2010skinbiopsy}，IENF 之計數對象為自真皮穿越表皮／真皮交界進入表皮之纖維；判定一條纖維是否符合此規則，需同時觀察其在表皮內與真皮側之走向。故本研究將分析區域定義為\textbf{表皮本身及其下方一段固定寬度之真皮}，使交界線兩側之纖維走向皆落入後續處理範圍。本研究於表皮遮罩 $M$ 上定義一個僅向下膨脹之運算

\begin{equation}
  M_{\text{ROI}} \;=\; \big(\,M \oplus K_{\text{offset}}\,\big) \cap M_{\downarrow},
  \label{eq:roi}
\end{equation}

\noindent 其中 $K_{\text{offset}}$ 為半徑 $\text{offset}$ 像素之圓形結構元；$M_{\downarrow}$ 為輔助遮罩（如圖~\ref{fig:roi-auxmask} 所示），對每個 $x$ 行 (column)，其值在 $y \le y_{\max}(x)$ 處為 1、其他為 0，其中 $y_{\max}(x) = \max\{\,y : M(y, x) > 0\,\}$ 為該行表皮遮罩內最高之 $y$ 座標。直觀上 $M_{\downarrow}$ 代表「不高於表皮頂部之像素」，藉由與等向性膨脹結果（圖~\ref{fig:roi-unrestricted}）取交集可避免膨脹向表皮上方溢出，從而確保感興趣區域僅包含表皮本身與其下方一段深度之真皮，並抑制切片邊緣之偽訊號，最終所得之 $M_{\text{ROI}}$ 如圖~\ref{fig:roi-restricted} 所示。本研究預設 $\text{offset} = 50$像素。

\subsection{影像增強}
\label{subsec:enhance}

$I$ 為 RGB 三通道影像，記其各通道為 $I = (I_r, I_g, I_b)$，其中 $I_g : \Omega \to [0, 255]$ 為綠色通道之灰階影像。由於 PGP 9.5 免疫染色之色彩資訊主要落在綠色通道，後續處理皆以 $I_g$ 作為輸入，並依序執行三個運算：形態學背景去除、CLAHE 局部對比增強、與多尺度 Sato 線狀結構濾波，分述如下。

\paragraph{形態學背景去除：} PGP 9.5 染色於切片各區域之強度本即不均勻，使整張影像存在一層慢變之背景偏移；若直接套用後續之對比增強，背景偏亮處將與真實纖維之響應混淆，不利於成本圖之建構。本研究以\textbf{白色頂帽} (white top-hat) 變換~\cite{serra1983image,soille1999morphological} 消除此一慢變背景，其形式定義為原影像與其形態學開運算之差：
\begin{equation}
  I_{\text{th}} \;=\; I_g - (I_g \circ K_{r_{\text{bg}}}),
  \label{eq:tophat}
\end{equation}

\noindent 其中 $K_{r_{\text{bg}}}$ 為尺寸（直徑）$r_{\text{bg}}$ 之圓盤形結構元，$\circ$ 為形態學開運算。其效果為僅保留尺度小於 $K_{r_{\text{bg}}}$ 之亮色細結構，並扣除尺度大於該結構元之慢變背景，使纖維被保留、染色不均項被扣除。輸入 $I_g$（圖~\ref{fig:enhance-green}）經此變換後得 $I_{\text{th}}$（圖~\ref{fig:enhance-tophat}），可見原本散布於纖維周圍之慢變背景被消除，僅留下纖維本身之亮色細結構。


\paragraph{對比受限直方圖均衡化 (CLAHE)：} 經背景去除後，$I_{\text{th}}$ 之整體灰階分布被壓縮於較窄之動態範圍內，纖維與其周圍之對比隨之降低；若直接以全域直方圖均衡化重映射，雖可恢復整張影像之灰階跨度，但會以單一灰階對應關係處理整張影像，無法針對表皮各局部區域內纖維與背景之相對對比作差異化處理。為此本研究採用 CLAHE~\cite{zuiderveld1994contrast} 對 $I_{\text{th}}$ 進行\textbf{局部}對比增強，記為
\begin{equation}
  I_{\text{eq}} \;=\; \mathrm{CLAHE}_{\,n_{\text{tile}},\,\beta}(I_{\text{th}}),
  \label{eq:clahe}
\end{equation}

\noindent 其中方塊尺度 $n_{\text{tile}}$ 控制局部適應之空間粒度，裁剪閾值 $\beta$ 抑制均勻區域之雜訊過度放大；輸出 $I_{\text{eq}}$ 如圖~\ref{fig:enhance-clahe} 所示。

\paragraph{多尺度 Sato 線狀結構濾波：} 經 CLAHE 增強後之 $I_{\text{eq}}$ 雖已凸顯纖維與背景之對比，但其中仍殘留與纖維結構無關之亮色雜訊，例如散在之染色亮點與小型團塊；此類響應於灰階上與纖維相近，僅憑灰階強度無法將其與真正之線狀結構區分。為抑制非線狀結構之響應、並僅突顯具管狀幾何特徵之區域，本研究採用 Sato 濾波器~\cite{sato1998three} 對 $I_{\text{eq}}$ 進行線狀結構濾波，記其原始響應為
\begin{equation}
  S \;=\; \mathrm{Sato}_{\,\Sigma}(I_{\text{eq}}),
  \label{eq:sato}
\end{equation}

\noindent 其中該濾波器基於 Hessian 矩陣之特徵值辨識亮色線狀區域，並對多尺度集合 $\Sigma = \{\sigma_{\min},\; \sigma_{\min}+1,\; \ldots,\; \sigma_{\max}\}$ 取各尺度響應之逐像素最大值，使不同粗細之纖維均能被有效偵測；$\sigma_{\min}, \sigma_{\max}$ 依目標纖維之最小與最大半寬選取。由於 $S$ 之動態範圍因影像而異，本研究再對其進行最小—最大線性正規化以對齊至固定區間 $[0, 255]$：
\begin{equation}
  I_{\text{enhanced}}(x, y) \;=\; 255 \cdot \frac{S(x, y) - \min_{(x', y') \in \Omega} S(x', y')}{\max_{(x', y') \in \Omega} S(x', y') - \min_{(x', y') \in \Omega} S(x', y')},
  \label{eq:sato-norm}
\end{equation}

\noindent 使纖維區域之響應接近 $255$、非纖維區域接近 $0$（如圖~\ref{fig:enhance-sato} 所示），為後續成本設計提供良好之輸入訊號。

在曲線狀結構偵測器之選擇上，本研究採用 Sato 濾波而非 Türetken 等人之多方向定向通量~\cite{turetken2013detecting} 等非 Hessian 變體，係考量 PGP 9.5 染色之 IENF profile 經形態學去背景與 CLAHE 對比正規化後，其管狀幾何已足夠規則，Sato 於 \texttt{scikit-image} 中已有成熟實作且計算成本顯著較低，便於重現；針對角膜共軛焦顯微等纖維形態更不規則之場景，定向通量類方法之導入屬可延伸之研究方向。


\subsection{像素成本圖}
\label{subsec:cost}

令 $\tilde{I}_{\text{enhanced}}(x, y) = I_{\text{enhanced}}(x, y) / 255 \in [0, 1]$ 為正規化後之纖維響應，本研究將像素成本定義為

\begin{equation}
  C(x, y) \;=\; e^{\,1 - \tilde{I}_{\text{enhanced}}(x, y)} - 1.
  \label{eq:cost}
\end{equation}

\noindent $C(x, y) \in [0,\; e - 1]$；後續路徑搜尋限制於 $M_{\text{ROI}}$ 內進行，感興趣區域外之像素不會被使用（如圖~\ref{fig:cost-full} 所示，黑色區域即為搜尋時不予考慮之像素）。式~\eqref{eq:cost} 具有三項理想性質：

\begin{itemize}
  \item \textbf{邊界收斂性}：$\tilde{I}_{\text{enhanced}} = 1$ 時 $C = 0$，$\tilde{I}_{\text{enhanced}} = 0$ 時 $C = e - 1 \approx 1.718$。
  \item \textbf{單調性}：$C$ 為 $\tilde{I}_{\text{enhanced}}$ 之嚴格遞減函數，響應越強成本越低。
  \item \textbf{對比放大}：由於指數函數 $e^x$ 之凸性，$\tilde{I}_{\text{enhanced}}$ 於 $[0.5, 1]$ 之強響應區段之成本變化相對平緩、於 $[0, 0.5]$ 之弱響應區段則陡峭上升；強、弱響應之成本差距被指數放大，使後續以累積成本為依據之路徑搜尋自然傾向沿高響應纖維前進、而避開橫切背景。
\end{itemize}

\noindent 此性質於圖~\ref{fig:cost-zoom} 之局部放大中可清晰觀察：纖維走向上之像素形成連續之低成本走廊，而周圍背景則普遍呈現高成本，二者之邊界明銳。

\section{多源區域擴張}
\label{sec:dijkstra}

本節之核心為「多源區域擴張」，奠基於經典之 Dijkstra 最短路徑演算法~\cite{dijkstra1959note}，並依本研究之目標影像與輸入特性作調整。

\subsection{連通元件之標記}
\label{subsec:cc}

令 $A_{\text{ROI}} = A \cap M_{\text{ROI}}$ 為限制於感興趣區域內之標註。以 $A_{\text{ROI}} > 127$ 進行二值化後執行\textbf{8-連通連通元件標記}，得到元件標記圖 $L : \Omega \to \{0, 1, \ldots, N\}$，其中 $N$ 為該切片所偵測出之纖維微粒總數，$L(x, y) = 0$ 為背景，$L(x, y) = i$（$i \ge 1$）代表像素 $(x, y)$ 屬於第 $i$ 個元件。每個連通元件即對應影像上一段連續染色之\textbf{纖維微粒} (particle)，其內部之像素已被視為同屬一條纖維，故無需再行細分，而元件之間是否屬於同一條纖維才是後續重建之核心問題。本研究即以此為基本單位，將每個元件視為一個獨立來源，於下節中同步執行多源區域擴張。

\subsection{擴張規則}
\label{subsec:dijkstra-rule}

以 第~\ref{subsec:cc}~節所得之元件標記圖 $L$ 作為多源輸入（如圖~\ref{fig:rg-components} 所示，圖中每個連通元件以不同顏色標示），擴張過程需為每個像素 $(x, y) \in \Omega$ 記錄三項資訊：
\begin{itemize}
  \item \textbf{累積成本} $D(x, y)$：自來源標註出發、沿最低成本路徑抵達 $(x, y)$ 所累積之成本，初始時標註像素為 $0$、其餘為 $\infty$；
  \item \textbf{所屬元件} $O(x, y) \in \{0, 1, \ldots, N\}$：提供此最低成本路徑之來源元件編號，$O(x, y) = 0$ 表示尚未被任一元件覆蓋；
  \item \textbf{前驅像素座標} $(x_{\text{prev}}(x, y), y_{\text{prev}}(x, y))$：到達 $(x, y)$ 之最佳路徑所來自之像素，供後續路徑回溯使用。
\end{itemize}

\noindent 演算法每次優先處理目前累積成本最小之未確定像素 $(x, y)$，並檢查其 8-連通鄰域中之每個鄰居 $(x', y')$。若經由 $(x, y)$ 抵達 $(x', y')$ 之成本低於 $(x', y')$ 目前記錄之成本，即

\begin{equation}
  D(x, y) + C(x', y') < D(x', y'),
  \label{eq:dijkstra-update}
\end{equation}

\noindent 則以此較低成本取代原值，令 $D(x', y') = D(x, y) + C(x', y')$，並將 $(x', y')$ 之擁有者設為 $O(x, y)$；同時記錄 $x_{\text{prev}}(x', y') = x$、$y_{\text{prev}}(x', y') = y$，表示目前到達 $(x', y')$ 的最佳路徑來自 $(x, y)$。被更新之 $(x', y')$ 隨即成為下一輪之候選像素，待其本身被處理時再進一步向其鄰域擴張。此擴張與標準單源 Dijkstra 演算法~\cite{dijkstra1959note} 之差別在於\textbf{初始堆中同時存在所有種子}。擴張完成後，每個像素皆被指派給累積成本最低之來源元件，所得之 $D(x, y)$ 場如圖~\ref{fig:rg-cost} 所示，可清楚觀察到自各來源沿低成本走廊向外漸增之累積成本；不同來源元件所形成之相鄰區域邊界，即構成後續相遇點搜尋之基礎。因此，整個擴張可視為在影像上形成一個\textbf{以成本為度量之 沃羅諾伊分割}~\cite{felzenszwalb2012distance}（見圖~\ref{fig:rg-voronoi}，每個像素被指派給其所屬之來源 $O(x, y)$）。

\section{相遇點偵測與元件層圖}
\label{sec:component-graph}

\subsection{相遇點之定義}
\label{subsec:meeting-def}

擴張完成後，我們於 $(O, D)$ 上搜尋\textbf{相鄰但屬於不同元件之像素對}。此處之相鄰關係以 8-連通定義：記 $N_8(x, y)$ 為像素 $(x, y)$ 之 8-連通鄰居集合。若像素 $(x, y)$ 與 $(x', y')$ 滿足 $(x', y') \in N_8(x, y)$，且同時滿足 $O(x, y) \ne 0$、$O(x', y') \ne 0$、$O(x, y) \ne O(x', y')$，則 $\bigl((x, y), (x', y')\bigr)$ 為一個\textbf{候選相遇點}；該相遇點之成本定義為

\begin{equation}
  w(x, y, x', y') \;=\; D(x, y) + D(x', y').
  \label{eq:meet-cost}
\end{equation}

\noindent 其中 $D(x, y)$ 與 $D(x', y')$ 分別表示由各自來源元件抵達邊界像素 $(x, y)$、$(x', y')$ 之累積成本，因此 $w(x, y, x', y')$ 可視為兩個元件經由此相鄰像素對相接時的路徑成本。圖~\ref{fig:meet-point} 示意了此一相遇點之偵測：於兩相鄰 沃羅諾伊 領域之交界處，凡屬不同元件之 8-連通像素對皆為候選相遇點。

\subsection{元件層圖之建構}
\label{subsec:build-gc}

以 $V_c = \{1, \ldots, N\}$ 為節點集。對 $V_c$ 中任一不重複之元件配對 $(a, b)$，先定義其候選相遇點集合為

\begin{equation}
  \mathcal{M}_{ab}
  =
  \bigl\{\bigl((x, y), (x', y')\bigr) : (x', y') \in N_8(x, y),\; O(x, y)=a,\; O(x', y')=b \bigr\}.
  \label{eq:meeting-set}
\end{equation}

\noindent 由於同一組元件之擴張邊界上可能存在多個候選相遇點，本研究僅保留其中成本最低者，作為此兩元件之連接位置，即

\begin{equation}
  \bigl((x_a, y_a),\, (x_b, y_b)\bigr) = \arg\min_{((x, y),(x', y'))\in\mathcal{M}_{ab}} w(x, y, x', y'),
  \label{eq:min-meeting}
\end{equation}

\noindent 式~\eqref{eq:min-meeting} 之目的為自候選相遇點集合 $\mathcal{M}_{ab}$ 中取出成本最低之像素對 $\bigl((x_a, y_a), (x_b, y_b)\bigr)$，作為此兩元件之連接位置；其對應之成本即定義為元件對 $(a, b)$ 之相遇成本：

\begin{equation}
  w_{ab} = w(x_a, y_a, x_b, y_b).
  \label{eq:min-meeting-cost}
\end{equation}

\noindent 其中 $(x_a, y_a)$ 與 $(x_b, y_b)$ 分別為此元件對 $(a, b)$ 之最低成本相遇點於 $a$ 側與 $b$ 側之像素座標，供後續路徑回溯使用。據此，元件層圖 $G_c$ 定義為

\begin{equation}
  G_c = \Bigl(V_c, E_c\Bigr),
  \label{eq:gc}
\end{equation}
\begin{equation}
  E_c = \bigl\{(a, b, w_{ab}) : \mathcal{M}_{ab} \ne \emptyset,\; a < b \bigr\}.
  \label{eq:gc-edges}
\end{equation}

\noindent 換言之，元件層圖 $G_c$ 以各纖維微粒為節點，凡其擴張領域相鄰者即以一條帶權邊相連，邊權 $w_{ab}$ 為兩元件間最低成本相遇點之路徑成本。圖~\ref{fig:meet-point} 一併呈現了由相遇點所導出之元件層圖：每條邊對應一組相鄰元件，其權重即沿成本圖連接兩者所需之最小代價。

  \caption[相遇點偵測與元件層圖之建構]{相遇點偵測與元件層圖之建構。多源區域擴張完成後，影像被劃分為各元件之成本-沃羅諾伊 領域；於相鄰但屬不同元件之像素對中取累積成本和最低者為該元件對之相遇點 $\bigl((x_a, y_a), (x_b, y_b)\bigr)$，並以其成本 $w_{ab}$ 作為元件層圖 $G_c$ 中對應邊之權重。}

\section{邊裁剪與最小生成森林}
\label{sec:prune-mst}

$G_c$ 之邊集在實務上常同時包含兩類連線：(i) 成本較低、代表真實纖維延續之合理連線；(ii) 成本極高、來自兩個遙遠元件之擴張前線於某處相遇之偽連線。若直接於 $G_c$ 上求取最小生成森林，後者亦可能被納入並造成跨越真皮之錯接。

本研究採用一個兩步策略，先以成本閾值排除明顯不可信之邊，再於剩餘圖上保留必要且低成本之連線：

\begin{enumerate}
  \item \textbf{閾值裁剪}：以閾值 $\tau$ 移除 $w_{ab} > \tau$ 之所有邊，得到 $G_c^{\text{pruned}}$。$\tau$ 為區分合理連線與偽連線之成本門檻，本研究設定 $\tau = 20$。
  \item \textbf{最小生成森林}：於 $G_c^{\text{pruned}}$ 上以克魯斯克爾演算法~\cite{kruskal1956shortest} 求取最小生成結構，記為 $G_{\text{mst}}$；由於 $G_c^{\text{pruned}}$ 可能不連通，$G_{\text{mst}}$ 實際為一個森林，每棵樹代表一條重建之纖維。
\end{enumerate}

此設計之主要作用在於：\textbf{閾值裁剪階段抑制偽連線、最小生成森林階段抑制冗餘連線}。兩者皆在元件層（而非像素層）上操作，計算成本極低，並且其輸出自然給出了纖維拓樸層級之碎片歸屬關係。圖~\ref{fig:graph} 比較了此兩步策略之各階段：未裁剪之 $G_c$（圖~\ref{fig:graph-full}）含大量橫跨真皮之高成本偽邊；經閾值 $\tau$ 裁剪後（圖~\ref{fig:graph-pruned}）此類偽邊被移除；最後之最小生成森林 $G_{\text{mst}}$（圖~\ref{fig:graph-mst}）進一步去除冗餘連線，使每棵樹對應一條重建之纖維。

\section{像素級拓樸之建構}
\label{sec:skeleton}

前述步驟已於元件層完成連結決策，得到最小生成森林 $G_{\text{mst}}$。然而 $G_{\text{mst}}$ 之每條邊僅記錄「哪兩個元件應相連」，尚未對應至影像上之實際像素軌跡。本節將 $G_{\text{mst}}$ 還原為像素層之具體形狀，依序經路徑回溯、橋接遮罩繪製與骨架化得到\textbf{骨架圖} $G_{\text{skel}}$，再經分段偵測與短樁修剪得到\textbf{修剪後拓樸圖} $G_{\text{trim}}$；後者即為供交叉點分析使用之最終像素級拓樸圖 $G$。

\subsection{最小生成森林邊之路徑回溯}
\label{subsec:path-backtrack}

最小生成森林 $G_{\text{mst}}$ 中之每條邊 $(a, b)$ 皆附帶一組最低成本相遇像素對 $\bigl((x_a, y_a), (x_b, y_b)\bigr)$。由此像素對出發，分別沿多源區域擴張階段所記錄之前驅指標 $x_{\text{prev}}, y_{\text{prev}}$ 逐像素回溯，即可各自得到一條通往元件 $a$、$b$ 種子之像素路徑。將兩側路徑於相遇處銜接、並反轉其中一側之順序，便串接成一條自種子 $\mathbf{s}_a$ 出發、行經 $(x_a, y_a)$ 與 $(x_b, y_b)$、終於種子 $\mathbf{s}_b$ 之\textbf{完整像素路徑}
\begin{equation}
  \Pi_{(a, b)} \;=\; \bigl[\mathbf{s}_a, \ldots, (x_a, y_a), (x_b, y_b), \ldots, \mathbf{s}_b\bigr].
  \label{eq:path}
\end{equation}
此路徑即為該最小生成森林邊於像素空間中之實際形狀（如圖~\ref{fig:bs-backtrack} 所示），並作為下一步繪製橋接遮罩之輸入。

\section{交叉點分析與有效跨越計數}
\label{sec:crossing}

\subsection{橋接遮罩與骨架化}
\label{subsec:bridge-skeleton}

將所有最小生成森林邊之像素路徑彙整起來，即可定義\textbf{橋接遮罩} $\mathcal{B} \in \{0, 1\}^{H \times W}$一張與影像同尺寸之二值遮罩，於任一最小生成森林路徑所經過之像素處取值為 $1$、其餘為 $0$：
\begin{equation}
  \mathcal{B}(x, y) \;=\;
  \begin{cases}
    1, & (x, y) \in \displaystyle\bigcup_{(a, b) \in G_{\text{mst}}} \Pi_{(a, b)}, \\[6pt]
    0, & (x, y) \notin \displaystyle\bigcup_{(a, b) \in G_{\text{mst}}} \Pi_{(a, b)}.
  \end{cases}
  \label{eq:bridge-mask}
\end{equation}
$\mathcal{B}$ 將分散於各邊之像素路徑整合為單一之像素層遮罩（如圖~\ref{fig:bs-pathmask} 所示），構成骨架化時新增區段之來源。

本研究後續以 Zhang--Suen 演算法~\cite{zhang1984fast} 萃取單像素寬骨架，惟該演算法對\textbf{單像素寬}之輸入較為敏感，此類細線於迭代過程中易被逐步消去而造成斷裂。為此，先以半徑 $r_d$（預設 $r_d = 1$）之小型圓形結構元對 $\mathcal{B}$ 進行膨脹，提升其厚度穩定性，記膨脹結果為
\begin{equation}
  \tilde{\mathcal{B}} \;=\; \mathcal{B} \oplus K_{r_d},
  \label{eq:bridge-dilated}
\end{equation}
如圖~\ref{fig:bs-dilated} 所示；再與原標註取聯集
\begin{equation}
  \mathcal{U} \;=\; \bigl(\,A > 0\,\bigr) \;\cup\; \tilde{\mathcal{B}}.
  \label{eq:union}
\end{equation}
所得之 $\mathcal{U}$ \textbf{同時保留既有之可信區段與新增之橋接區段}（圖~\ref{fig:bs-union}），確保重建結果與原標註兼容。最後再以 Zhang--Suen 演算法將 $\mathcal{U}$ 細化為單像素寬之骨架（圖~\ref{fig:bs-skeleton}），並轉換為以 $(x, y)$ 座標為節點、像素間相鄰為邊之\textbf{骨架圖}
\begin{equation}
  G_{\text{skel}} \;=\; (V_{\text{skel}}, E_{\text{skel}}).
  \label{eq:gskel}
\end{equation}


\subsection{分段偵測}
\label{subsec:segment}

骨架圖 $G_{\text{skel}}$ 仍為像素級之節點—邊結構，尚需進一步切分為具拓樸意義之單位。首先依節點之度數（degree）將 $V_{\text{skel}}$ 分為三類：度為 $1$ 之\textbf{端點} (endpoint)、度 $\ge 3$ 之\textbf{分支點} (branchpoint)、以及度為 $2$ 之\textbf{中繼節點}(如圖~\ref{fig:bs-pruned} 所示)；其中端點與分支點合稱\textbf{邊界節點}。一條\textbf{線段} (segment) 即定義為兩端皆為邊界節點、而中間僅由中繼節點串接之路徑。如此切分使任兩條線段不共用任何邊，且全部線段之邊之聯集恰為 $E_{\text{skel}}$，故線段集合構成 $E_{\text{skel}}$ 之一個分割；而每一線段對應一段\textbf{無分支之纖維弧}。

\subsection{短樁線段之修剪}
\label{subsec:stub-prune}

分段後，若某線段之總像素長度小於 $\ell_{\min}$（預設 $3\,\text{像素}$）且其邊界節點至少一端為端點（即為懸掛之短樁，如圖~\ref{fig:bs-skeleton} 中紅色圓圈所標示），則將其自 $G_{\text{skel}}$ 中移除，再於剩餘骨架上重新進行分段偵測。此一步驟可有效抑制骨架化之離散化誤差所產生之小毛刺，避免後續區域標記將其誤計為跨越事件。修剪並重新分段所得之拓樸圖記為
\begin{equation*}
  G_{\text{trim}} \;=\; (V_{\text{trim}}, E_{\text{trim}}),
\end{equation*}
\noindent 其中 $G_{\text{trim}}$ 為後續交叉點分析所依據之最終像素級拓樸，如圖~\ref{fig:bs-pruned} 所示之結果。


在 第~\ref{sec:skeleton}~節已建構出經分段與短樁修剪之像素級拓樸 $G_{\text{trim}}$ 後，本節依序執行三個步驟以將其轉換為可計數之 IENFD：(i) 於纖維層以微粒涵蓋數篩除偽神經，得到僅由可信神經組成之 $G_{\text{cov}}$；(ii) 於 $G_{\text{cov}}$ 上對節點進行區域標記，並依此判定跨越邊；(iii) 將跨越邊以所屬線段為單位彙整，計數有效跨越事件。

\subsection{纖維層之微粒涵蓋篩選}
\label{subsec:coverage-filter}

$G_{\text{trim}}$ 之每個連通分量代表一條\textbf{獨立重建之神經}（可能由多段線段串接而成）。然其中或有由極少數微粒拼接而成者，多半源自孤立之染色雜訊或斷續嚴重之背景結構，不應視為合法神經纖維。為此，本研究於後續區域分析之前先施加一道纖維層篩選。

記 $G_{\text{trim}}$ 之第 $i$ 個連通分量為 $T_i$，定義 $T_i$ 所涵蓋之纖維微粒數為
\begin{equation}
  n_{\text{cov}}(T_i) \;=\; \bigl|\,\{\, k \in \{1, \ldots, N\} : \exists\, (x, y) \in T_i,\; L(x, y) = k \,\}\,\bigr|,
  \label{eq:particle-cov}
\end{equation}
即 $T_i$ 之像素節點於原始纖維微粒標籤圖（第~\ref{subsec:cc}~節）上所對應之微粒數。僅保留滿足
\begin{equation}
  n_{\text{cov}}(T_i) \;\ge\; N_{\min}
  \label{eq:particle-min}
\end{equation}
之連通分量（預設 $N_{\min} = 1$），其聯集記為
\begin{equation*}
  G_{\text{cov}} \;=\; (V_{\text{cov}}, E_{\text{cov}}) \;=\; \bigcup_{i:\, n_{\text{cov}}(T_i) \,\ge\, N_{\min}} T_i.
\end{equation*}
$G_{\text{cov}}$ 即為通過纖維層篩選之拓樸圖（如圖~\ref{fig:crossing-coverage} 所示），後續區域標記與跨越判定皆以其為依據。

\subsection{區域標記與跨越判定}
\label{subsec:region}

對 $G_{\text{cov}}$ 中每個節點 $\mathbf{v} = (x, y)$，依其於表皮遮罩 $M$ 之取值定義其所屬區域
\begin{equation}
  R(\mathbf{v}) \;=\;
    \begin{cases}
      0, & M(\mathbf{v}) > 0, \\
      1, & \text{otherwise}.
    \end{cases}
  \label{eq:region-label}
\end{equation}
\noindent 其中 $R(\mathbf{v}) = 0$ 表示節點 $\mathbf{v}$ 落於\textbf{表皮}內、$R(\mathbf{v}) = 1$ 表示落於\textbf{真皮}內。任一於 $E_{\text{cov}}$ 之邊 $(\mathbf{u}, \mathbf{v})$，若其兩端節點分屬不同區域，即 $R(\mathbf{u}) \ne R(\mathbf{v})$，則稱該邊為一條\textbf{跨越邊} (crossing edge)。圖~\ref{fig:crossing-point} 視覺化所偵測之跨越邊位置。

\subsection{有效跨越計數}
\label{subsec:effective-count}

在上述區域標記完成後，本研究依\textbf{線段}（而非邊）為單位計算跨越數；遵循 EFNS/PNS 切片計數規範~\cite{jointtaskforce2010skinbiopsy}，一條線段即使包含多個跨越邊亦僅計為一次。偶然搭上 DEJ 一小段即折返之毛刺已於 第~\ref{subsec:stub-prune}~節之短樁修剪階段一併排除，故於此階段不再對線段於兩側區域之延伸長度施加額外限制。

綜上所述，一條線段被計為一次有效跨越，需\textbf{同時}滿足：(i) 其所屬連通分量已通過微粒涵蓋篩選（第~\ref{subsec:coverage-filter}~節）而保留於 $G_{\text{cov}}$ 中；(ii) 至少包含一條跨越邊。滿足之線段總數 $N_{\text{cross}}$ 即為 AEL 輸出之有效跨越數，最終計入之線段如圖~\ref{fig:crossing-effective} 所示。若已知切片之表皮長度（可自 $M$ 之上緣輪廓計算），$N_{\text{cross}}$ 可用於計算 IENFD，並與專家人工計數直接比較。

\section{本章小結}
\label{sec:method-summary}

綜合前述各節之說明，AEL 自輸入影像至有效跨越數之完整流程可整理為演算法~\ref{alg:ael}。本研究提出之 AEL 演算法以多源區域擴張為核心，將原本不完整之纖維微粒標註逐步整合為一個於像素層級具一致性之拓樸圖：擴張過程於成本圖上自動劃分各元件之 沃羅諾伊 領域，並於相鄰領域邊界處產生具最小累積成本之相遇點，藉此重建因斷裂而失聯之纖維延續關係。為避免遠距離元件之高成本相遇被誤納，AEL 進一步在元件層圖上施以閾值裁剪並計算最小生成森林，使每棵樹自然對應一條重建後之纖維、同時抑制偽連線與冗餘連線。最後將樹邊之像素路徑與原微粒標註取聯集後骨架化，並於骨架上以線段為單位執行區域標記與有效跨越判定；輸出之 $N_{\text{cross}}$ 結合切片之表皮長度即和 IENFD 相比，完成自破碎之纖維微粒至可量化指標之端到端流程。


\begin{algorithm}[htbp]
  \caption{Annotation Expansion Linker}
  \label{alg:ael}
  \textbf{Input:} histological image $I$, epidermis mask $M$, particle annotation $A$; parameters $\{\text{offset}, r_{\text{bg}}, n_{\text{tile}}, \beta, \sigma_{\min}, \sigma_{\max}, \tau, r_d, \ell_{\min}, N_{\min}\}$.\\
  \textbf{Output:} pixel-level topology graph $G_{\text{trim}}$ and effective crossing count $N_{\text{cross}}$.
  \begin{enumerate}
    \item $M_{\text{ROI}} \gets$ the mask obtained by dilating $M$ downward by $\text{offset}$ pixels, so that the analysis domain covers the epidermis and a fixed dermis strip beneath it.
    \item $I_{\text{enhanced}} \gets$ the result of removing the slowly varying background from the green channel $I_g$, applying CLAHE for local contrast enhancement, running the multi-scale Sato vesselness filter, and masking by $M_{\text{ROI}}$.
    \item $C \gets \exp(1 - \tilde{I}_{\text{enhanced}}) - 1$, the pixel cost map derived from the normalized vesselness response.
    \item $L \gets$ the label map of the connected components of $A \cap M_{\text{ROI}}$;\; $N \gets \max L$, the total number of components used as expansion seeds.
    \item $(O, D, \text{prev}_y, \text{prev}_x) \gets$ the per-pixel owner, accumulated cost, and predecessor coordinates produced by running a multi-source region expansion on $C$ with all components in $L$ as simultaneous seeds.
    \item $\mathcal{P} \gets$ the set of inter-component meeting points obtained by scanning each pixel's 8-connected neighborhood and, for each adjacent component pair, keeping only the lowest-cost pixel pair.
    \item $G_c \gets$ the component-level graph built from $\mathcal{P}$, with one node per component and one edge per adjacent component pair.
    \item $G_c^{\text{pruned}} \gets$ the same graph after removing edges whose weight exceeds the threshold $\tau$.
    \item $G_{\text{mst}} \gets$ the minimum spanning forest of $G_c^{\text{pruned}}$, in which each tree corresponds to one reconstructed fiber.
    \item $G_{\text{skel}} \gets$ the single-pixel-wide skeleton obtained by backtracking each $G_{\text{mst}}$ edge into a pixel path via $(\text{prev}_y, \text{prev}_x)$, dilating the resulting bridge mask by radius $r_d$, taking the union with $A$, and applying Zhang--Suen thinning.
    \item $G_{\text{trim}} \gets$ the topology obtained by splitting $G_{\text{skel}}$ into segments at all boundary nodes and removing dangling stubs shorter than $\ell_{\min}$.
    \item $G_{\text{cov}} \gets$ the subgraph of $G_{\text{trim}}$ retained after discarding fibers whose covered particle count falls below $N_{\min}$, leaving only the trustworthy fibers.
    \item $G_{\text{cov}} \gets$ the same graph with every node labeled as lying above, within, or below the epidermis according to $M$.
    \item $N_{\text{cross}} \gets$ the number of effective crossings counted on $G_{\text{cov}}$ following the EFNS/PNS counting rules.
  \end{enumerate}
\end{algorithm}
